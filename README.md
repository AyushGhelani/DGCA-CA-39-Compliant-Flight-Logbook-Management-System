# ✈️ DGCA CA-39 Compliant Flight Logbook Management System

## 📌 About the Project

The **Flight Logbook Management System** is a Java-based application designed to digitize and simplify the management of pilot flight records. It helps users maintain flight details, track flying hours, and organize logbook information in a structured format.

The project uses **Java** for application logic and **MySQL** for database management.

## 🛠️ Technologies Used

- **Programming Language:** Java
- **Database:** MySQL
- **Database Tool:** MySQL Workbench

## 🎯 Project Objectives

- Digitize traditional flight logbook records.
- Store and manage flight details efficiently.
- Track pilot flight hours.
- Organize flight records for easier access and management.
- Support structured flight logbook maintenance.

## 📚 Learning Outcomes

- Understanding Java application development.
- Working with MySQL databases.
- Understanding database connectivity and CRUD operations.
- Learning the structure of a full-stack Java project.

## ⚠️ Disclaimer

This is an educational software project. Its actual regulatory compliance with DGCA CA-39 requirements has not been independently verified.
